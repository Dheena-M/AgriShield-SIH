# AgriVision reference artifacts

This folder preserves the supplied presentation/report generator sources and slide montage as historical reference material.

The source material contains claims about a 19-class trained disease classifier and 81.49% validation accuracy. Those claims do not describe the current AgriShield implementation and must not be used as AgriShield model evidence. The current implementation and its limitations are documented in the in-app **Data & models** page.

`node_modules` was intentionally excluded because it is a machine-specific dependency link, not project source.
